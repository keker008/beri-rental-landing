# Бери — сервис проката вещей

Лендинг на Vue 3, Vite и Tailwind CSS. Каталог, фильтр и форма работают в браузере. Форма показывает введённые данные, но не отправляет их на сервер. На странице между каталогом и блоком «Как это работает» размещён компонент `src/components/AdSlot.vue`.

## Запуск

Нужен Node.js 22 и pnpm 11.

```bash
pnpm install
pnpm dev
```

Для сборки статических файлов:

```bash
pnpm build
```

Результат находится в папке `dist`. Для локальной проверки сборки: `pnpm preview`.

## Рекламное место

Компонент принимает `size="banner"` или `size="sidebar"`. Можно передать `width` и `height` как строки CSS, например `width="100%" height="160px"`. Сейчас показан только плейсхолдер без рекламного кода и отслеживания посетителей.

## Публикация

В `.github/workflows/deploy.yml` подготовлена сборка для GitHub Pages. После создания публичного репозитория с веткой `main` нужно выбрать **Settings → Pages → Build and deployment → GitHub Actions**. При отправке кода workflow соберёт и опубликует `dist`. Путь к ресурсам определяется именем репозитория автоматически.

Для Cloudflare Pages: подключите репозиторий, задайте команду сборки `pnpm build` и каталог результата `dist`. Значение `base` по умолчанию равно `/`.
