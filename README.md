# Бери — сервис проката вещей

Один проект для заданий по адаптивной верстке, Vue, Tailwind CSS и публикации сайта. Главная страница содержит каталог, фильтр, преимущества, отзывы, варианты срока проката, форму заявки, FAQ и рекламное место. Личный кабинет содержит регистрацию, вход, восстановление пароля, загрузку Excel, таблицу вещей, историю изменений и управление ролями.

## Как запустить

Нужны Node.js 24 и pnpm 11. Откройте два терминала в папке проекта:

```bash
pnpm install
pnpm server
```

```bash
pnpm dev
```

Сайт откроется по адресу `http://localhost:5173`. Сервер API работает на `http://localhost:3001`. После сборки `pnpm build` можно открывать сайт по адресу `http://localhost:3001` — сервер отдаёт и страницы, и API.

## Как показать работу

Первый зарегистрированный пользователь получает роль администратора. После регистрации сохраните показанный код восстановления. Других готовых пользователей и тестовых записей нет.

В разделе «Личный кабинет» можно добавить вещь вручную или загрузить файл `.xlsx`. На первом листе должны быть столбцы «Название», «Категория», «Цена за день»; первая строка — заголовки. Записи сохраняются в SQLite, файлы — в папку `storage/uploads`. В таблице по 10 записей на странице, есть кнопка «Загрузить ещё». Для добавления и редактирования используется одно модальное окно. Администратор видит историю изменений с данными до и после и может менять роли пользователей.

API находится по пути `/api/v1`. Действия с вещами используют GET, POST, PUT и DELETE. Все запросы из Vue выполняются через `fetch` без перезагрузки страницы. Секреты паролей хранятся в виде хеша, сессии — в таблице SQLite.

## Публикация

Сайт опубликован на [GitHub Pages](https://keker008.github.io/beri-rental-landing/). На этом адресе кабинет работает в демонстрационном режиме: записи, учетные записи и список загруженных файлов сохраняются только в браузере пользователя; сами Excel-файлы не сохраняются. Если очистить данные браузера или открыть сайт на другом устройстве, эти записи не появятся. Для работы с сервером, SQLite и хранением файлов запускайте проект локально. В задании назван Voyager для Laravel; здесь вместо него сделана простая админка на Vue и Node.js, потому что проект построен на JavaScript.
